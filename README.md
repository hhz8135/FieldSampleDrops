**FieldSampleDrops** turns nearby enemy kills into collectible sample drops in **HellForge**. When the host reaches a kill threshold, a sample spawns at the enemy's death location—pick it up and extract with it just like a regular sample.

#### Key Features

- **Host Proximity Tracking:** Only enemy kills credited to the host within **30 m** count by default (adjustable from **1 to 300 m**).
- **Separate Sample Counters:** Common, Rare, and Super samples track independently, dropping every **20 / 40 / 75** eligible kills by default.
- **In-Game Configuration:** Adjust all three kill thresholds and the distance limit (`1–300 m`) via the mod menu. Changes take effect on the **next mission**.
- **Session Persistence:** Kill progress carries over when the host is reinforced and resets at the start of each mission.
- **Difficulty & Treasure Map Support:**
  - By difficulty: Common on **D1–D11**, Rare on **D4–D11**, and Super on **D6–D11**.
  - Optional **Treasure Map 1.4.0** integration: uses Treasure Map data when it can confirm a sample type for the current mission, and falls back to mission difficulty otherwise (opening the tactical map is optional).

**中文说明**



**FieldSampleDrops** 会将房主附近的击杀转化为可拾取的样本掉落。达到击杀阈值后，样本会在怪物死亡位置生成，正常拾取并带走撤离即可。

- **击杀统计：** 仅统计房主本人的近距离击杀，默认范围为 **30 米**（可在菜单中调整为 **1–300 米**）。
- **独立计数：** 普通、稀有、超级样本拥有独立计数器，默认分别每 **20 / 40 / 75** 次有效击杀掉落 1 个。
- **菜单设置：** 可在菜单中分别调整三档阈值与距离上限，修改后**下一局生效**。
- **进度机制：** 房主阵亡增援后保留当前击杀进度，每局任务开始时重置。
- **难度与联动支持：** 支持 **D1–D11（N11）**——按难度默认开启范围为普通 D1–D11、稀有 D4–D11、超级 D6–D11；可选联动 **Treasure Map 1.4.0**（能确认当前任务样本类型时优先采用其数据，否则回退到按难度判定，无需手动打开战术地图）。
